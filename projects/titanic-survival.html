Titanic Survival Analysis

An interactive dashboard exploring who survived the Titanic's maiden voyage and why — built from the Kaggle "Titanic: Machine Learning from Disaster" dataset (891 passenger records). The goal: turn a well-known dataset into a tool people can actually filter, sort, and query, rather than a static set of charts.

APPROACH

From raw CSV to interactive tool

Data preparation

  • Parsed passenger titles (Mr, Mrs, Master, Officer, Noble…) out of the raw name strings
  • Derived family size and a "traveling alone" flag from SibSp + Parch
  • Binned ages into six life-stage groups and filled the 2 missing embarkation ports
  • Extracted deck letter from the cabin field where available

Key findings

  • Sex was the strongest predictor: women survived at 4x the rate of men
  • Class compounded that gap — 1st class women survived at 96.8%, 3rd class men at 13.5%
  • Passengers with family aboard survived at 50.6% vs. 30.4% traveling alone
  • Children under 12 survived at 57.4%, well above the ship-wide average

Build notes

  • All 891 records ship as embedded JSON — no backend or database calls
  • Every chart and the passenger table recompute live from the active filter state
  • Built with vanilla JS and Chart.js; layout and type system designed from scratch
